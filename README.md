# 🧠 Práctica 1 · Programación

Este repositorio reúne los **ejercicios de pseudocódigo** de la Práctica 1 del módulo de Programación, resueltos con **PSeInt**: traza de un programa, cálculo de una nómina, estadísticas de números y factorial.

## 🛠️ Tecnologías Usadas

- **PSeInt** 💻 (intérprete de pseudocódigo)
- **Pseudocódigo** 📝 (variables, condicionales y bucles)
- **Bloc de notas** 🗒️ (para la traza del ejercicio 1)

## 📋 Ejercicios

| # | Archivo | Descripción |
|---|---------|-------------|
| 1️⃣ | `ejercicio1.txt` | Traza (tabla de la verdad) de un programa: evolución de las variables `a`, `b` y `c` |
| 2️⃣ | `ejercicio2.psc` | Cálculo del importe neto de una nómina (pagas extras, pluses, IRPF y Seguridad Social) |
| 3️⃣ | `ejercicio3.psc` | Lectura de enteros hasta introducir 0: contador y suma de positivos/negativos, mínimo y máximo |
| 4️⃣ | `ejercicio4.psc` | Factorial de un número, validando que sea mayor o igual que 1 |

## 🚀 Cómo Usarlo

1. Clona o descarga el repositorio.
2. Instala [PSeInt]
3. Abre el archivo `.psc` que quieras probar (`Archivo > Abrir`).
4. Pulsa **Ejecutar** (`F9`) y sigue las instrucciones por pantalla.
5. Abre `ejercicio1.txt` con cualquier editor de texto para ver la traza.
